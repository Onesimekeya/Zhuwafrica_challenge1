# Susu Group Tracker
A Python program for managing a rotating savings group (Susu).

## Features
- Creation of a group with a fixed weekly contribution (in GHS).
- Addition of unique members.
- Recording of contributions (with support for partial payments).
- Week closure with validation of full payments and pot distribution.
- Detailed reports on the current week's status and payout history.
